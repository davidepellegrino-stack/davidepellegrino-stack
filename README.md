## Projects

| Project | What it does |
|---|---|
| [**portfolio-risk-analyzer**](https://github.com/davidepellegrino-stack/portfolio-risk-analyzer) | Market risk engine. Five models forecast one-day 99% VaR and 97.5% Expected Shortfall for an 8-stock EU/US portfolio in EUR, backtested out of sample over 2,028 days (Kupiec, Christoffersen, Basel traffic light). Normal models are rejected: 44 exceedances against 20 expected. |
| [**sanctions-privacy-coins**](https://github.com/davidepellegrino-stack/sanctions-privacy-coins) | My M1 thesis. Do sanctions announcements move privacy coins? Event study (BMP, Corrado tests) and difference-in-differences on 37 hand-collected sanctions events, 2014 to 2026. The events dataset is in the repository. |
| [**credit-scoring-model**](https://github.com/davidepellegrino-stack/credit-scoring-model) | Default prediction on synthetic loan data: logistic regression vs random forest vs gradient boosting in scikit-learn pipelines, stratified 5-fold CV. Logistic regression ranks best (CV AUC 0.69, test AUC 0.67). |
| [**event-window**](https://github.com/davidepellegrino-stack/event-window) | One market event, measured. A weekly event study with code and results, published every Tuesday on LinkedIn. Nº01: the Binance hack. |

## Event Window

Every Tuesday I pick one market event and measure it with the same method as my thesis: market model, abnormal returns, t-statistics. The code, the results and the caveats are in [event-window](https://github.com/davidepellegrino-stack/event-window), so anyone can re-run the numbers.
